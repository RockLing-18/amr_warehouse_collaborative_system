# Edge HTTP API 错误码

## 1. 响应结构

所有 Edge HTTP API 使用统一响应结构：

```json
{
  "code": 0,
  "msg": "success",
  "data": {}
}
```

- `code = 0` 表示成功。
- `code != 0` 表示失败，`msg` 给出可读错误原因。
- `data` 仅在成功或需要返回业务数据时使用。

## 2. 通用错误码

| code | HTTP 状态码 | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功。 |
| 40001 | 400 | 参数缺失或格式错误。 |
| 40002 | 400 | 参数值非法。 |
| 40101 | 401 | 未授权；V1 当前无鉴权，保留备用。 |
| 40301 | 403 | 无权限；V1 当前无鉴权，保留备用。 |
| 40401 | 404 | 资源不存在。 |
| 40501 | 405 | 方法不允许。 |
| 40901 | 409 | 请求冲突或状态冲突。 |
| 50001 | 500 | 服务器内部错误。 |
| 50002 | 503 | 服务暂不可用。 |

## 3. 业务错误码

| code | 含义 | 适用接口 |
| --- | --- | --- |
| 41001 | `robot_id` 不存在或未注册。 | Bootstrap、任务相关。 |
| 41002 | `task_id` 已存在且不允许重复创建。 | `POST /api/tasks`。 |
| 41003 | `robot_ids` 为空。 | `POST /api/tasks`。 |
| 41004 | `robot_ids` 中存在不可用 AMR。 | `POST /api/tasks`。 |
| 41005 | 任务不存在。 | `GET /api/tasks/{task_id}`、取消。 |
| 41006 | 任务已进入终态，不能取消。 | 取消任务。 |
| 41007 | 货物申请数量超过 `pending_quantity`。 | 货物申请。 |
| 41008 | 货物申请消息重复。 | 货物申请。 |
| 41009 | 货物不存在于任务中。 | 货物申请。 |
| 41010 | AMR 不属于该任务。 | 货物申请、状态上报。 |

## 4. 使用规则

- HTTP 状态码与业务 `code` 同时返回。
- 业务层应根据 `code` 判断，而不是只判断 HTTP 状态码。
- 新增错误码时，必须同步更新本文件。
